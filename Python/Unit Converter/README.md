This project focuses on creating a flexible conversion system that can easily be expanded with additional units and categories.

## Features

- Convert between multiple measurement categories
  - Length
  - Weight
  - Temperature
  - Volume
  - Time
  - Speed
  - Data Storage
  - Area
  - Energy
- Input validation
- Error handling for invalid selections and values
- Reusable conversion logic using base units
- Menu-driven command-line interface

## Example

### Example 1

```text
Select a category:
1. Length
2. Weight
3. Temperature
...

Please select a unit type: 1(user input)

Lenght Units:
1. Millimeter
2. Centimeter
3. Inch
4. Foot
...

Please enter a selection in the form of (1-8) for start and end unit: 1-2(user input)
Please enter a value to convert: 10(user input)

Answer: 1.0
```
