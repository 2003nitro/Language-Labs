# Calculator

## Description

A command-line calculator capable of evaluating mathematical expressions while following standard order of operations.

## Features

- Supports parentheses
- Supports decimals
- Order of operations
- Input validation
- Error handling

## Example

```text
Expression:
(5 + 3) * 2 - 4

Result:
12
```

## Invalid Input

```text
Expression:
5+
```

## Concepts Practiced

- User Input
- Variables
- Functions
- Loops
- String Parsing
- Error Handling
